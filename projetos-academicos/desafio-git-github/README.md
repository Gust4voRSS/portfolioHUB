# Desafio Git + GitHub — Criação de Repositório com Versionamento

**Tipo:** Projeto acadêmico · Bootcamp I (Entrega Intermediária) · ADS — 2º semestre
**Tecnologias:** Git, GitHub, GitHub Pages, Markdown, HTML, CSS

## 📌 Objetivo
Criar um repositório no GitHub com projetos acadêmicos e pessoais, aplicando boas práticas de versionamento, documentação e compartilhamento, integrado ao LinkedIn.

## ✅ Requisitos atendidos

| # | Requisito | Onde está |
|---|---|---|
| 1 | Planejamento do repositório e estrutura de diretórios | [documentacao/planejamento.md](../../documentacao/planejamento.md) |
| 2 | Projeto inicial (página web) versionado — v1.0 + alterações | [index.html](../../index.html), tags `v1.0` e `v1.1` |
| 3 | Pastas por projeto e README.md em cada uma | este arquivo e [portfolio-web](../../projetos-pessoais/portfolio-web/) |
| 4 | Página no GitHub Pages | https://gust4vorss.github.io/PortfolioHUB/ |
| 5 | Repositório público + integração com LinkedIn | [documentacao/linkedin.md](../../documentacao/linkedin.md) |
| 6 | Apresentação de 5 minutos (YouTube) | [documentacao/roteiro-apresentacao.md](../../documentacao/roteiro-apresentacao.md) |

## 🧠 O que aprendi
- Diferença entre repositório local (Git) e remoto (GitHub).
- Ciclo `add → commit → push` e uso de tags para marcar versões.
- Escrita de documentação em Markdown.
- Publicação de site estático com GitHub Pages.
