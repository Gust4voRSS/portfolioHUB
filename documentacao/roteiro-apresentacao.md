# 6. Roteiro da Apresentação (≈ 5 minutos — YouTube)

| Tempo | O que mostrar | O que falar |
|---|---|---|
| 0:00–0:30 | Rosto ou site aberto | Apresentação: nome, curso (ADS, 2º semestre), objetivo do vídeo. |
| 0:30–1:15 | Página inicial do repositório no GitHub | O que é o PortfolioHUB e para que serve. Mostrar o README com badges e a tabela de projetos. |
| 1:15–2:00 | Pastas `projetos-academicos`, `projetos-pessoais`, `documentacao` | Como planejei a estrutura: uma pasta por projeto, cada uma com README. Abrir o `planejamento.md`. |
| 2:00–3:00 | Aba **Commits** e aba **Tags** (v1.0 e v1.1) | O fluxo `add → commit → push`, o padrão de mensagens (`feat:`, `docs:`) e como marquei a versão 1.0 e depois enviei as alterações (v1.1). Abrir o `CHANGELOG.md`. |
| 3:00–4:00 | Site no GitHub Pages | Navegar pelas seções: Sobre, Trajetória (Exército com Honra ao Mérito, Jovem Aprendiz), Projetos e Contato. Mostrar no celular/modo escuro. |
| 4:00–4:40 | Perfil do LinkedIn | Mostrar o projeto na seção Projetos e o link em Destaque. |
| 4:40–5:00 | Site ou rosto | Fechamento: o que aprendi e próximos projetos que vou adicionar. |

## Dicas de gravação
- Use o OBS Studio ou o gravador do próprio Windows (**Win + Alt + R**) ou do Mac (**Cmd + Shift + 5**).
- Deixe o zoom do navegador em 125% para facilitar a leitura.
- No YouTube, publique como **Não listado** se não quiser deixar público, e cole o link no PDF da entrega.
