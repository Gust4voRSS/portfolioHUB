## Passo a passo no LinkedIn

### a) Seção "Projetos"
Perfil → **Adicionar seção** → **Recomendado** → **Adicionar projetos**.

- **Nome:** PortfolioHUB — Repositório de Projetos com Git e GitHub
- **Descrição:**
  > Repositório que reúne meus projetos acadêmicos e pessoais do curso de Análise e Desenvolvimento de Sistemas, organizado com versionamento Git (tags v1.0 e v1.1), documentação em Markdown e um site de portfólio publicado com GitHub Pages.
- **Competências:** Git, GitHub, HTML, CSS, Markdown
- **Mídia/link:** https://gust4vorss.github.io/PortfolioHUB/
- **Associado a:** Análise e Desenvolvimento de Sistemas

### b) Seção "Destaque"
Perfil → **Adicionar seção** → **Destaque** → **Adicionar link** → cole o link do site.

### c) Informações de contato
Perfil → **Informações de contato** → **Site** → tipo *Portfólio* → link do GitHub Pages.
