# Portfólio Web

**Tipo:** Projeto pessoal
**Tecnologias:** HTML5, CSS3, GitHub Pages
**Site:** https://gust4vorss.github.io/PortfolioHUB/

## 📌 Descrição
Página pessoal que apresenta minha trajetória, meus projetos e meus contatos. É o projeto inicial do repositório e serve como vitrine profissional, com link no LinkedIn.

## ✨ Funcionalidades
- Seções: Sobre, Trajetória, Projetos e Contato.
- Layout responsivo (funciona no celular).
- Modo claro/escuro automático, seguindo o sistema.
- Sem dependências: só HTML e CSS.

## 🗂️ Arquivos
| Arquivo | Função |
|---|---|
| `/index.html` | Estrutura e conteúdo da página |
| `/assets/style.css` | Estilos e responsividade |

> Os arquivos do site ficam na raiz do repositório porque o GitHub Pages publica a partir da raiz da branch `main`.

## 🔀 Versões
| Versão | Mudanças |
|---|---|
| v1.0 | Primeira versão: estrutura da página, seção Sobre e Projetos |
| v1.1 | Seção Trajetória, modo escuro, ajustes de responsividade e links |

## ▶️ Como publicar
1. No GitHub: **Settings → Pages**.
2. Em *Source*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Salve e aguarde 1–2 minutos.
